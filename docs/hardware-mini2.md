# Станция Мини 2

Профиль `station-mini2` (`HardwareProfile`). Данные основаны на документации
проекта Pulsar и прежней лабораторной станции; на этой ревизии прошивки
аппаратная часть нового демона ещё не проверялась.

## Звук

- Захват: ALSA `default`, 48 кГц, 6 каналов S16_LE.
- Каналы 0–3 — PDM-микрофоны, 4–5 — петля TDM усилителя (аппаратный
  референс). Это позволяет подавлять эхо собственным NLMS даже без VQE.
- Вывод: ALSA `default` (softvol Master над dmix), 48 кГц, stereo.
- Громкость: `amixer -D default sset Master N%`; кривая линейна в процентах.
- VQE: пресет `yandexmini_2`, библиотека
  `/system/vendor/quasar/libs/libyandex_evil.so`, модели
  `/system/vendor/quasar/vqe_models`. `libtflite.so` и `libiconv.so`
  подгружаются заранее из каталога прошивки.
- Выход VQE `omni` (тип 6) — 16 кГц, используется как канал распознавания.
- Если VQE недоступен: среднее микрофонов → КИХ 48→16 кГц → NLMS по
  референсу. Качество на реальной комнате не измерялось.

Проверка на колонке:

```bash
/data/jarvis/current/jarvisctl --config /data/jarvis/config.toml doctor
# войти в логи:
tail -f /data/jarvis/log/jarvisd.log
```

В журнале при старте: `VQE 'yandexmini_2': N входных кадров -> M выходных`
или предупреждение о переходе на собственный DSP.

## Светодиоды

6 RGB-пикселей через sysfs:

```
/sys/class/leds/mini2:red:ring1/brightness
...
/sys/class/leds/mini2:blue:ring6/brightness
```

Яркость 0–255, ограничение `hardware.led_brightness`. Анимации: выключено,
слушает (синее дыхание), думает (бегущая точка), говорит (зелёная пульсация),
ошибка (красный), мут (тусклый красный), громкость (дуга). Запись идёт
только при изменении значения; 20 кадров/с.

Если файлов нет, демон пишет предупреждение и работает без кольца.

## Часы

На части ревизий панель отсутствует. Семь сегментов на цифру:

```
/sys/class/leds/mini2:white:clockA1/brightness   # A..G, позиции 1..4
/sys/class/leds/mini2:white:clockPLUS1/brightness
/sys/class/leds/mini2:white:clockPLUS2/brightness
```

Вспомогательные `DEGREE` и `MINUS` гасятся. Часы показывают время с
мигающим двоеточием; при активном таймере — `MM:SS`, после срабатывания
возвращаются к времени. Яркость — значение сегмента (не общий current).
Если панель не найдена, часы отключаются, демон продолжает работу.

## Кнопки

evdev-устройство `sar0_pad0`:

- `KEY_VOICECOMMAND` 582 / настроенный `action_key` — начать/отменить/прервать;
- `KEY_VOLUMEUP` 115, `KEY_VOLUMEDOWN` 114 — шаг громкости;
- `KEY_MUTE` 113, если есть — программный мут.

Узел ищется в `/proc/bus/input/devices` по имени; путь не угадывается.
События читаются блокирующим потоком, повторные `value=2` игнорируются.

## Мут микрофонов

Аппаратный переключатель на GPIOZ_3 (глобальный 414), активный низкий
уровень. Демон только читает
`/sys/class/gpio/gpio414/value` раз в 400 мс; экспорт и настройку не делает.
`0` — микрофоны выключены: активация и VAD не работают, звук останавливается,
кольцо красное. Переопределение — `hardware.mic_mute_gpio`.

## Ограничения

- Часы и датчик освещённости есть не на всех экземплярах; код это учитывает.
- Прошивка может отличаться набором каналов VQE и путями; при несовпадении
  используйте `vqe = "auto"` и смотрите журнал.
- Уровень `vqe_0` у моделей разный; усиление детектора `gain` подбирается
  записью и `wake-test`, а не по паспорту.
- Аппаратные проверки обязательны; см. [testing.md](testing.md).
